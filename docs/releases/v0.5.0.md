# Primary Wallpaper Agent v0.5.0 Preview

Choose a picture for the Windows primary display and a separate picture shared by every secondary display. Secondary displays remain black by default. Assignments follow the current primary/secondary roles when monitors are switched, connected or removed; no per-monitor image preferences are stored.

- Added **Primary display / All secondary displays** above the existing image strip. Switching the viewed role does not save or change wallpaper. Selecting a picture applies immediately; **Use black** restores the secondary default.
- The four-picture recent library is shared. Both roles keep their current cached image even after it falls out of the library. Undo is separate for each role and preserves the other role and preferences.
- Secondary pictures can be prepared with one monitor connected or before the first primary selection, without activating an unconfigured watcher. Unrelated Windows primary changes remain protected when editing secondaries. A pending primary switch can rebase currently trusted role images.
- Per-monitor apply skips assignments already correct while retaining topology, readback and rollback checks. DPI changes keep the compact layout while respecting a manually resized viewport.

Full includes .NET 10 Windows Desktop Runtime; Slim requires a compatible installed .NET 10 Windows Desktop Runtime x64. Both are single-file Windows x64 apps. Enable **Include preview releases** in About, check for updates and select **Update and restart**. Full stays Full; Slim stays Slim.

## Settings compatibility

Older settings retain their existing primary picture and black secondary default. The first image edit writes schema 4 and preserves the exact pre-upgrade settings as **settings-before-schema4.json** beside settings.json. The backup is not rotated with logs or exported in support ZIPs.

**v0.4.5 and earlier cannot read schema 4.** To downgrade, exit the running app, preserve the new settings separately and restore the saved pre-upgrade backup as settings.json. New secondary selections are not represented in the old format. Do not run two versions at once. [Compatibility and checks](https://github.com/thep497/PrimaryWallpaperAgent/blob/main/docs/testing/SECONDARY-WALLPAPER-TEST.md).

## Verification and scope

The user tested the 0.5.0 review and approved publication on 23 October 2026. Eighteen automated suites cover legacy defaults, exact pre-upgrade backups, first-run/offline configuration, one/three/five simulated monitors, role swaps/hotplug, independent Undo, shared history, rollback, Thai/English UI, themes and DPI. Real ConfigForm/AgentContext message loops use generated images and fake wallpaper/startup backends. Full/Slim packages are checked separately for signed metadata, hashes, standalone startup and preflight; schema-4 fixtures with custom secondary pictures also reopen without changing settings.

These checks do not establish every physical-monitor/projector, Virtual Desktop or Remote reconnect scenario. The existing documented physical checks remain separate. [Role verification](https://github.com/thep497/PrimaryWallpaperAgent/blob/main/docs/testing/SECONDARY-WALLPAPER-TEST.md).

## Download warning and removal

The EXEs are not Authenticode-signed. Edge/Windows may show limited-reputation or unknown-publisher warnings. Read [download and SHA-256 instructions](https://github.com/thep497/PrimaryWallpaperAgent#download-warning-and-sha-256) before running. Keep SmartScreen enabled. The signed auto-update manifest is separate from Windows publisher signing.

To uninstall, turn Start with Windows off, exit from the tray and remove the EXE. Data removal is optional; current wallpaper remains until changed in Windows. [Uninstall instructions](https://github.com/thep497/PrimaryWallpaperAgent#uninstall).
