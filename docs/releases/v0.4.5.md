# Primary Wallpaper Agent v0.4.5 Preview

Connecting a new monitor now restores the saved picture to the current Windows primary display and black to the other active extended displays after stable, complete display samples. Windows-restored wallpaper paths during an observed monitor-set transition no longer require choosing the image again. An unfamiliar image on the unchanged monitor set still pauses for explicit adoption; cold starts still need a safe initial baseline.

- Fixed Settings after DPI/resolution changes: compact thumbnail and single-line filename rows, resizing in both directions, and footer buttons that remain visible. Only the content scrolls when the window is too small.
- Centralized daily logs under runtime/logs. Restarts append; logs roll at about 2 MiB. Managed retention targets 30 days/50 MiB while preserving active/locked files.
- Added **About > Open log folder / Export diagnostics** in Thai and English. Export produces one ZIP with a seven-day timeline and selected display diagnostics, including older app runs. It excludes photos/full settings backups and redacts known path/device identifiers. Review the archive before sharing publicly.
- Improved mapping-wait/recovery records and unique snapshots so repeated attempts do not overwrite earlier evidence.

Full includes .NET 10 Windows Desktop Runtime; Slim requires a compatible installed .NET 10 Windows Desktop Runtime x64. Both are single-file Windows x64 apps. Enable **Include preview releases** in About, check for updates and select **Update and restart**. Full stays Full; Slim stays Slim.

## Verification and scope

The user approved the corrected Settings review on 22 October 2026. Seventeen automated suites cover policy/hotplug, persistence, diagnostics/export, Thai/English layout, themes and updates using generated images and fake wallpaper/startup backends. The reported 150% DPI layout was reproduced before the fix and verified afterward, including long cached filenames, vertical/horizontal resizing, scrolling and minimize/restore. Full/Slim distributions are separately checked for signatures, hashes, fresh/reopened standalone startup and read-only preflight.

Physical-monitor/projector and Remote reconnect scenarios remain subject to the documented checks; simulated displays and native DPI messages do not establish all hardware results. [Diagnostics/DPI evidence](https://github.com/thep497/PrimaryWallpaperAgent/blob/main/docs/testing/LOGGING-DPI-TEST.md), [new-monitor checks](https://github.com/thep497/PrimaryWallpaperAgent/blob/main/docs/testing/NEW-MONITOR-TEST.md).

## Download warning and removal

The EXEs are not Authenticode-signed. Edge/Windows may show limited-reputation or unknown-publisher warnings. Read [download and SHA-256 instructions](https://github.com/thep497/PrimaryWallpaperAgent#download-warning-and-sha-256) before running. Keep SmartScreen enabled. The signed auto-update manifest is separate from Windows publisher signing.

To uninstall, turn Start with Windows off, exit from the tray and remove the EXE. Data removal is optional; current wallpaper remains until changed in Windows. [Uninstall instructions](https://github.com/thep497/PrimaryWallpaperAgent#uninstall).
