# Primary Wallpaper Agent v0.4.3 Preview

A smaller Settings layout with a single image-selection strip, plus a persistent app theme.

- Removed the separate large wallpaper preview. Recent pictures remain visible; the selected image is first, with its filename underneath and the full name available on hover.
- Added **System / Light / Dark** in Thai and English. Changes apply and save immediately; System follows Windows app-color changes while the app is open.
- Settings, About/update controls, click-help and the tray menu share the chosen theme. Native file/message dialogs follow Windows.
- Existing settings default to System. Image selection and Undo retain the theme; a failed save restores the prior choice and colors.
- Theme changes do not set wallpaper, alter startup registration or change Windows color preferences.

Full includes .NET 10 Windows Desktop Runtime; Slim requires a compatible installed .NET 10 Windows Desktop Runtime x64. Both are single-file Windows x64 apps. Enable **Include preview releases** in About, check for updates and select **Update and restart**. Full stays Full; Slim stays Slim.

## Verification and scope

The user approved the local review build on 20 October 2026. Fourteen automated suites cover persistence/rollback, live system notifications, bilingual layout, existing image recovery and updater behavior using generated images and fake wallpaper/startup backends. Full/Slim packages are checked separately for signatures, hashes, standalone startup and read-only preflight.

The app body uses its own palette on Windows 10; the explicit dark title-bar attribute is limited to Windows 11 build 22000+. This release is not a new physical Windows 10 compatibility test. [Theme verification](https://github.com/thep497/PrimaryWallpaperAgent/blob/main/docs/testing/THEME-TEST.md).

## Download warning and removal

The EXEs are not Authenticode-signed. Edge/Windows may show limited-reputation or unknown-publisher warnings. Read [download and SHA-256 instructions](https://github.com/thep497/PrimaryWallpaperAgent#download-warning-and-sha-256) before running. Keep SmartScreen enabled.

To uninstall, turn Start with Windows off, exit from the tray and remove the EXE. Data removal is optional; current wallpaper remains until changed in Windows. [Uninstall instructions](https://github.com/thep497/PrimaryWallpaperAgent#uninstall).
