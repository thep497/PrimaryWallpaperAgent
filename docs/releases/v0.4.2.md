# Primary Wallpaper Agent v0.4.2 Preview

Recover a chosen wallpaper from the app's saved copies when Windows reports a missing source file, including after display/session changes.

- **Recent pictures:** four distinct successful choices, including the current picture, with the last used first. Click a thumbnail to apply immediately.
- Saved copies and the recent list survive app restarts. The original source file is not required for those choices.
- Existing installations immediately offer their configured cached picture. Additional history accumulates as pictures are selected; unrelated old files are not scanned or imported.
- A missing Windows wallpaper path now explains that the file is unavailable and points to Recent pictures or Browse.
- Cached pictures are hash checked again before use. Missing/changed historical items do not prevent Settings from opening.
- Unknown Windows wallpaper changes still pause for an explicit choice. Previous pictures are not silently accepted or reapplied.
- Thai/English thumbnails fit without scrolling; the image preview remains visible. Undo image retains its separate one-level behavior.

Full includes .NET 10 Windows Desktop Runtime; Slim requires a compatible installed .NET 10 Windows Desktop Runtime x64. Both remain single-file Windows x64 downloads. Existing v0.4.x users can enable **Include preview releases** in About, check for updates, and select **Update and restart**. Full stays Full; Slim stays Slim.

## Download warning and removal

The EXEs are not Authenticode-signed. Edge/Windows may show limited-reputation or unknown-publisher warnings. Read [download and SHA-256 instructions](https://github.com/thep497/PrimaryWallpaperAgent#download-warning-and-sha-256) before running. Keep SmartScreen enabled.

To uninstall, turn Start with Windows off, exit from the tray and remove the EXE. Data removal is optional; current wallpaper remains until changed in Windows. [Uninstall instructions](https://github.com/thep497/PrimaryWallpaperAgent#uninstall).

## Verification and scope

13 standard suites include history ordering/persistence, exact rollback, deleted original sources, altered cache rejection, compact bilingual UI and a live fake-backend agent reproducing paused 3-to-1-to-3 recovery with a changed primary. Package checks cover Full/Slim identity, signature/hash and standalone renamed EXEs. Tests do not call the native wallpaper or startup writers.

The user reported successful v0.4.1 operation on Windows 10 in a Hyper-V Enhanced Session. That report does not establish all Windows 10 editions/builds or physical-console compatibility; this v0.4.2 fix still needs confirmation in that same VM scenario.
