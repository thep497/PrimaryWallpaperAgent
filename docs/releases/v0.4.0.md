# Primary Wallpaper Agent v0.4.0 Preview

Automatic update checks with user-controlled installation, plus Full and Slim single-file Windows x64 downloads.

## Choose a download

- **PrimaryWallpaperAgent-Full-win-x64.exe** — recommended. Includes .NET 10 Windows Desktop Runtime.
- **PrimaryWallpaperAgent-Slim-win-x64.exe** — smaller download; requires a compatible .NET 10 Windows Desktop Runtime x64 already installed. .NET Framework 4.x or only ASP.NET Core Runtime is insufficient.

Both are single-file apps with the same wallpaper behavior. About shows the running version and package type.

## Updating from v0.3.1 or earlier

Exit the existing tray instance. Download v0.4.0 manually once and keep it at the intended permanent path. To keep the startup registration, replace the existing EXE at its existing path/name, or toggle Start with Windows off/on from the new location.

Existing settings and cached pictures are retained. Older adjacent settings/assets remain in legacy folder mode; newer installs use per-user data.

## New update behavior

- About contains automatic checks, optional Preview releases, Check for updates, release notes and Update and restart.
- Default channel is Stable. Enable **Include preview releases** to receive later Preview builds.
- Automatic checks begin after approximately one minute, then at most daily after success; failures retry no more than hourly. Manual checks are available immediately.
- A notification announces each newly found version once. No update is downloaded or installed until you click Update and restart.
- Full updates to Full; Slim updates to Slim. Package type is embedded in the app rather than inferred from its filename.
- The downloader verifies an ECDSA-signed manifest and exact size/SHA-256, checks that the candidate starts, then hands off to a temporary copy of the current EXE.
- The helper waits for the old process to exit, replaces the EXE at its existing path and checks ready startup. If startup fails, it attempts to restore and reopen the previous EXE.
- Settings/pictures are not replaced. Startup remains pointed at the same executable path. Pause is preserved for successful restarts.
- Slim preflight checks runtime availability; it does not install or upgrade .NET automatically.
- Offline or failed update checks leave the wallpaper engine running.

## Validation and limits

12 standard automated suites pass. Additional real-process fixtures exercise a copied parent, helper and candidate for Full/Slim success and rollback. Tests use generated assets and no native wallpaper/startup writer. Full/Slim package checks include rename, fresh/reopened data and update preflight.

The manifest has an update signature; the EXEs are not Authenticode-signed. Windows 10 has not been validated for this app. Physical projector, >3 displays, DPI transitions and startup after logon remain pending. Health acknowledgment verifies app startup, not every future wallpaper operation.
