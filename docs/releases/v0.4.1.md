# Primary Wallpaper Agent v0.4.1 Preview

Full and Slim single-file Windows x64 downloads with automatic update checks and user-controlled installation.

- **Full** includes .NET 10 Windows Desktop Runtime.
- **Slim** requires a compatible installed .NET 10 Windows Desktop Runtime x64.
- About provides daily checks, optional Preview releases, release notes and Update and restart.
- Updates preserve Full/Slim type, executable path, settings, cached images and startup registration.
- Signed manifest, exact size/hash, executable preflight, parent/helper handoff and startup health checks precede/guard replacement.
- The previous EXE is retained for recovery; failed startup triggers an attempted restore/reopen.

## v0.4.1 correction

Cloud-sync metadata can mark ordinary directories as reparse points. The updater now distinguishes actual junction/symlink redirection from non-link metadata, avoiding false refusal in synced project/install data folders. Actual links remain rejected. The classification was checked against this machine's synced folder metadata and a real junction.

This supersedes v0.4.0 Preview. Versions before v0.4.0 need one manual download/upgrade. Exit the old tray instance before opening this download. Keep the original EXE path/name to preserve startup, or toggle Start with Windows off/on after moving it.

Default channel is Stable; enable Include preview releases for future previews. Updates are not installed silently. Slim never installs .NET automatically.

12 standard suites plus real parent/helper/candidate process tests cover Full/Slim success and rollback. Package tests verify signed assets, renamed EXEs, fresh/reopened data and preflight. No native wallpaper/startup backend is used by these tests.

Manifest signing is ECDSA; EXEs are not Authenticode-signed. Windows 10, projector, >3 physical displays, DPI transitions and logon-startup coverage remain unverified. Health acknowledgment verifies startup rather than every operation in a future release.
