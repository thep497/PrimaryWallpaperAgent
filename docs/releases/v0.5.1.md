# Primary Wallpaper Agent v0.5.1 Preview

Newer wallpaper settings no longer prevent this version from starting solely because their schema number is higher or they contain additional fields. Read the fields this version understands, use defaults for missing optional settings and continue without a compatibility prompt.

- Unrecognized saved theme and display-check interval choices fall back to System and 1 second. Supported choices retain their values.
- Opening alone preserves the original settings file. An explicit settings change writes this version's known fields/schema and can discard fields from newer versions. Returning to a newer version fills missing options with defaults; discarded selections are not recovered automatically.
- JSON syntax, known-field types and cached-image path/hash checks remain enforced. The signed update manifest and updater preferences are unchanged.

## Compatibility

This behavior starts with v0.5.1. Existing v0.4.x EXEs retain their original schema restriction and need the documented pre-upgrade settings backup when downgrading. Do not run two versions at once. Adding fields should use optional defaults; changing the meaning/type of existing required fields is not automatically compatible.

Full includes .NET 10 Windows Desktop Runtime; Slim requires a compatible installed .NET 10 Windows Desktop Runtime x64. Both are single-file Windows x64 apps. Enable **Include preview releases** in About to receive this preview. Full stays Full; Slim stays Slim.

## Verification

The new compatibility suite exercises future/legacy schemas, nested extra fields, missing defaults, exact settings preservation on opening, failed-save rollback and explicit-save field removal using generated images and fake desktop/startup backends. Regression and standalone Full/Slim checks are recorded in [config compatibility verification](https://github.com/thep497/PrimaryWallpaperAgent/blob/main/docs/testing/CONFIG-COMPATIBILITY-TEST.md).

This patch changes configuration loading, not display mapping or wallpaper policy. Automated results do not close the existing physical-monitor/Remote/Virtual Desktop checks. The user authorized publication after automated verification for this patch.

## Download warning

EXEs remain unsigned for Windows publisher verification. Read the [download and SHA-256 instructions](https://github.com/thep497/PrimaryWallpaperAgent#download-warning-and-sha-256). Keep SmartScreen enabled. The signed auto-update manifest remains separate from Authenticode signing.
