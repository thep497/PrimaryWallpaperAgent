# Primary Wallpaper Agent v0.3.0 Preview

A Windows x64 single-file download with first-run setup, immediate settings and compact Thai/English UI.

## Download and run

Download **PrimaryWallpaperAgent.exe** and keep it in a permanent local folder. This self-contained build includes .NET 10; no separate runtime installation is required. SHA256SUMS.txt is provided for verification.

Exit older running instances. Set Windows background to **Picture / Fill**, launch the EXE and choose a picture or use the current primary image. First launch waits for that explicit choice before changing wallpaper.

## Changes

- Language, polling and Start with Windows apply immediately.
- Image selection applies immediately; one-level Undo restores only the image.
- Compact Settings with clickable ? help and no scroll area.
- Display checking continues while Settings stays open.
- Simplified tray; removed Check wallpaper again.
- Official application/tray icons and Thai/English UI.
- Fresh-install setup without private trial assets.
- New-install settings/cache/logs in %LOCALAPPDATA%\PrimaryWallpaperAgent.
- Startup uses the actual EXE path, including renamed executables.

Existing adjacent settings/assets stay in legacy folder mode without silent migration. Exit before replacing the binary. Start with Windows is opt-in for each account. Moving/renaming after opting in requires toggling the option off/on at the new location.

## Validation and limits

All nine automated suites pass. The renamed packaged EXE works with isolated fresh data and shared .NET runtime lookup disabled, loads both languages/icons, and reopens successfully. Package checks make no native wallpaper or startup registry writes.

This is a **prerelease**. Physical-console recovery after Remote, projector, >3 physical displays, DPI transitions and startup after logon remain pending. Spotlight/slideshow and separate images per Virtual Desktop are unsupported. Exit keeps current wallpaper assignments. The binary is unsigned.
